<h2>一、清单怎么用：先划否决项</h2>
<h3>否决项只有六条</h3>
<p>六条里任意一条不满足，直接排除，不用再比价格。这六条分别是：当天可连通、出口为住宅类型、一号一线可独占、归属信息可查、支持试用或短期起订、有明确售后渠道。前四条是技术底线，后两条是交易保障，缺哪条后面都会变成成本。</p>
<h3>软指标用来排序</h3>
<p>六条都过之后，再用带宽、延迟、城市覆盖、计费方式这些软指标排序。软指标没有绝对好坏，取决于你的使用场景。长期挂机的看稳定性权重高，偶尔登录的看单价权重高，不需要统一标准。</p>

<h2>三、三项软指标，可以谈</h2>

<h3>带宽与并发</h3>
<p>问清单条出口的带宽上限和并发连接数。长期挂机看重的是并发稳定而不是峰值带宽，尤其多环境同时在线时，连接数上限比带宽更容易成为瓶颈。这一项可以谈，多数服务商能按需调整。</p>
<h3>延迟与抖动</h3>
<p>看平均延迟更看抖动。平均两百毫秒但抖动很小，体验好过平均一百二十毫秒但时不时跳到五百。让对方提供一段二十四小时的探测记录，比自己临场测十分钟有说服力。</p>
<h3>城市与运营商覆盖</h3>
<p>你要用的城市能不能稳定给出条数，是长期扩量的前提。只在一个城市有几条线的供应商，扩到三十条时往往给不出同城资源，只能跨城补，跨城就意味着定位不一致。这一项在初期就要问清上限。</p>

<h2>四、售后条款要问到什么颗粒度</h2>
<h3>四个问题必须问</h3>
<p>第一，报障渠道是什么，工单、群还是电话；第二，响应时长承诺多少，工作日与节假日是否一致；第三，换线是否收费，多久内免费；第四，未用时长或流量怎么折算。四个问题的答案要写进订单备注或合同，口头承诺在纠纷时几乎无效。</p>
<h3>自营与转售的差别</h3>
<p>自营意味着线路和服务团队是同一方，出问题能直接改配置；转售则是层层转达，排查时间成倍增加。判断方式很直接：问对方能不能提供 ASN 层面的调整、能不能指定上游，答不上来的基本都是转售。这一点比价格重要。</p>

<h2>五、开通当天的验收动作</h2>
<h3>五步走完再确认收货</h3>
<p>第一步，连通性测试，从真实使用的机器访问目标站点三次，记录耗时。第二步，归属核对，把 IP 信息截图存档。第三步，稳定性探测，连续一百次请求记录超时。第四步，隔离确认，用第二个账号登录看是否互不影响。第五步，把上述结果填进验收表并注明日期。</p>
<h3>验收表要留档</h3>
<p>验收结果不只是给自己看，后续报障时它是最有力的证据。一条「开通首日超时三次」的记录，能让对方快速定位而不是让你反复复现问题。表格用在线文档存，团队共享，别放在个人电脑里。</p>

<h2>常见问答</h2>
<h3>报价便宜三成，能不能先用着看？</h3>
<p>答：如果六项硬指标都过，便宜三成当然可以试。但如果便宜的前提是共享出口或机房类型，省下的钱很快会在验证和换号上还回去。判断标准不是单价，而是「单账号每月的综合成本」，把线路费、环境费、人力时间一起折算。</p>
<h3>怎么确认一条线是不是真的独占？</h3>
<p>答：让服务商提供该 IP 的分配记录，看是否只对应你的账号；同时自己在不同时段查同一 IP 的登录行为日志，若出现你从未操作过的访问，基本可判定非独占。这两步都不复杂，付款前就该做。</p>
<h3>售后响应慢，有没有办法约束？</h3>
<p>答：把响应时长写进合同，并约定超时的补偿方式，比如按天折算费用或免费换线。没有书面约定的「随时响应」在实操中很难追责。小额采购也建议留一份订单备注，写明关键承诺。</p>
<h3>开通当天不通，算不算违约？</h3>
<p>答：看合同怎么写。多数服务商的条款里会写「工作日二十四小时内开通」，当天不通并不必然违约。所以付款前要问清开通时限，并把「当天可连通」作为验收条件写进去，达不到就换下一家。</p>
